# 🦁 LiderKids — Prezident Maktabiga Tayyorlov Ta'lim Platformasi

**LiderKids** — 1–4-sinf boshlang‘ich sinf o‘quvchilarini Prezident maktabi imtihonlariga tayyorlovchi, bolalarbop interaktiv va gamifikatsiyalashgan ta'lim platformasi.

---

## 🌟 Asosiy Xususiyatlar va Gamifikatsiya

1. **Shercha (Mascot) Ekotizimi:**
   - **1-sinf:** *Kichkintoy shercha* (Baby cub) 🐾
   - **2-sinf:** *O‘ynoqi shercha* (Playful cub) ⚡
   - **3-sinf:** *O‘smir sher* (Teen lion) 🎯
   - **4-sinf:** *Qirol sher* (Adult King lion) 👑
   - O‘quvchining sinfiga qarab SVG qahramonning ko‘rinishi, xarakteri va ifodalari dinamik o‘zgaradi. Bosilganda quvnoq animatsiyalar namoyish etiladi.

2. **Mukofot va Motivatsiya Tizimi:**
   - 🪙 **Tangalar (Coins):** Har bir test to‘g‘ri yechilganda hisobga **+10 tanga** qo‘shiladi.
   - 🔥 **Olovchalar (Streak/Energy):** Har bir video dars ko‘rilganda **+1 olovcha** beriladi.
   - ⭐ **XP & Daraja:** Har bir harakat Sherchaning tajriba progress barini to‘ldiradi.
   - 🏆 **Yutuqlar (Achievements):** Maxsus nishonlar va shon-sharaf medali.

3. **3 Asosiy Yo‘nalish:**
   - 🧮 **Matematika:** Sonlar sehri, qulay va tezkor hisoblash usullari, geometriya.
   - 💡 **Muammoli masalalar (Problem Solving):** Hayotiy mantiqiy jumboqlar, tezkor qarorlar.
   - 🧠 **Tanqidiy fikrlash (Critical Thinking):** Ketma-ketliklar, fazoviy tasavvur va chuqur tahlil.

4. **Interaktiv Testlar (/quiz):**
   - Darhol natija (Instant feedback), Web Audio API orqali quvnoq ovozli effektlar, g‘alabali konfetti animatsiyasi va to‘liq tushuntirishlar.

5. **Video Darslar (/lessons):**
   - Mavzulashtirilgan video darslar, tushuntirish nuqtalari va darsni yakunlash mexanikasi.

---

## 🚀 Texnik Stek

- **Framework:** [Next.js](https://nextjs.org/) (App Router) + TypeScript
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/) & [Canvas-Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Audio:** Web Audio API (Sintezlangan bolalarbop tovushlar)
- **State Management:** React Context API + LocalStorage

## 💻 Mahalliy muhitda ishga tushirish
